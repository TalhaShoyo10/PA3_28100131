Qualitative annotation (42 responses)

How to annotate
format_ok
Did the response follow the format the prompt asked for? JSON prompts: is the answer valid JSON in the requested shape? Template prompts: did it fill the given template? Plain prompts have no required format, so use N/A.
coherent
Is the response on-topic and sensible as an answer to this question? Partly = relevant but rambling, contradictory, or drifting.
repetition
Does it loop or repeat the same sentences or phrases? A truncated response that ran into the 512-token cap often does.
math_framing
Does it bring in mathematics that the question did not ask for (equations, "Let x be", step-by-step arithmetic, "The answer is: N")?
inappropriate
Harmful, hostile, unethical or otherwise inappropriate content for the question.
excerpt
A short quote that supports your judgement. Select text in the response and press "Use selection", or type it.
