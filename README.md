# ATML PA3

Code, configs, split IDs and machine-readable results for PA3 (EE-5102/CS-6304, Fall 2026). Seed 6304 everywhere.

## Environment
- Local (CPU, Windows, Python 3.12): data preparation, Task 3 offline analysis, analysis scripts. Pins in `requirements.txt`.
- Kaggle (GPU T4 x2, Python 3.13, torch 2.11.0+cu130): all GPU work. Each job installs `transformers==4.57.6`, `datasets==4.8.5`, `huggingface_hub==0.36.2` (and `lm_eval==0.4.13` for evaluation) and writes its `pip freeze` to `logs/pip_freeze.txt` in the job output.
- Commands below assume the repo root as working directory and `PYTHONPATH=.`.

## Task 1: LLM fine-tuning (Qwen3-0.6B on MetaMathQA)
1. Data: `python -m task1_llm_ft.data.build_metamath` writes `splits/task1/metamath_kept_ids.json`, exclusion counts and `results/task1/data_stats.json`.
2. Probe set: `python -m task1_llm_ft.diagnostics.probe_set` writes `splits/task1/probe_set_ids.json`.
3. Training (one config per run in `configs/task1/`): `python -m task1_llm_ft.train --config configs/task1/<run>.yaml --out outputs/task1`.
4. Evaluation: `python -m task1_llm_ft.eval.run_lm_eval --model <path or hub id> --condition <name> --tasks gsm8k|likelihood --out outputs/task1_eval`; adapters are merged first with `python -m task1_llm_ft.eval.merge_adapters`.
5. Diagnostics and qualitative: `task1_llm_ft/diagnostics/weight_space.py`, `task1_llm_ft/diagnostics/activations.py`, `task1_llm_ft/eval/qualitative.py`.

## Task 2: VLM (SigLIP -> MLP connector -> Qwen3-0.6B)
1. Data + splits: `python -m task2_vlm.data.build_data --coco-root <coco2014> --vqa-cache <dir> --out <dir>`.
2. Features: `python -m task2_vlm.features.cache_siglip --splits <splits/task2> --coco-root <coco2014> --out <features>`.
3. Training: `python -m task2_vlm.train --config configs/task2/main_196.yaml --splits <splits/task2> --features <features> --out outputs/task2`.
4. Final evaluation: `python -m task2_vlm.eval.final_eval --config configs/task2/main_196.yaml --splits ... --features ... --weights <stage3_end.pt> --out ...`.

## Task 3: Test-time compute
Supplied rollouts are expected at the `data_root` in `configs/task3/offline.yaml`.
1. `python -m task3_ttc.data.load_join` (alignment checks), `python -m task3_ttc.data.splits`, `python -m task3_ttc.data.normalize` (answer groups, correctness, frozen scorer in `results/task3/scorer.json`).
2. `python -m task3_ttc.offline.run_budgets` and `python -m task3_ttc.offline.signal_analysis`.
3. `python -m task3_ttc.adaptive.select_on_dev` (freezes `results/task3/adaptive_selected.json`), then `python -m task3_ttc.adaptive.evaluate_heldout`.
4. Live generation (GPU): `python -m task3_ttc.live.generate --out <dir> --shard i --num-shards 2`, then `python -m task3_ttc.live.summarize --records <dir>/live_records_shard*.jsonl`.
5. Figures and examples: `python -m task3_ttc.analysis.plots`, `python -m task3_ttc.analysis.examples` (writes `results/task3/examples/`).

## Tables and figures
- Task 1: `python -m task1_llm_ft.analysis.tables`, `python -m task1_llm_ft.analysis.plots`; annotation page `python -m task1_llm_ft.analysis.annotation_page`.
- Task 2: `python -m task2_vlm.analysis.plots`, `python -m task2_vlm.analysis.tables`, `python -m task2_vlm.analysis.examples`.
- Report tables (LaTeX, numbers only) and required-figure copies: `python report/tools/make_report_assets.py`.

## Kaggle jobs
Generated by `PYTHONPATH=. python kaggle/make_job.py <name>` into `kaggle/jobs/<name>/` and pushed with `kaggle kernels push -p kaggle/jobs/<name> --accelerator NvidiaTeslaT4`. Code reaches Kaggle as the private dataset `pa3-code` (`kaggle/make_code_dataset.py`), never by cloning the repo.

| Job | Contents |
|---|---|
| `pa3-t1-smoke` | 20 updates of every Task 1 method (timing / memory) |
| `pa3-t1-eval-baseline` | first baseline evaluation with automatic batch size; stopped (too slow) and superseded by `pa3-t1-eval-four` |
| `pa3-t1-full-l2sp` | Full FT and Full FT + L2-SP, one per GPU |
| `pa3-t2-data` (CPU) | Task 2 data build (its splits are committed in `splits/task2/`) |
| `pa3-t2-features` (CPU) | SigLIP feature caching |
| `pa3-t1-lora4-oplora` | LoRA-4 and OPLoRA-16, one per GPU |
| `pa3-t1-lora16-t2` | LoRA-16; Task 2 training + final evaluation |
| `pa3-t1-eval-four` | evaluation of baseline, Full FT@625, Full FT@1250, L2-SP (GSM8K batch size 48) |
| `pa3-t3-live` | Task 3 live generation, one shard per GPU |
| `pa3-t1-final` | adapter merges and evaluation, weight-space and activation diagnostics, qualitative generation |
